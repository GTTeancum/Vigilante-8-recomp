# Vigilante 8 Classic — release candidate 2026-09-24

A Windows x64 build of Vigilante 8: 2nd Offense with the original Vigilante 8 crew, enhanced textures, HD/widescreen presentation, Super Dreamland 64, and local multiplayer for up to four players.

**Start here: [SETUP.md](SETUP.md).** Extract the ZIP, run `Vigilante8PC.exe`, select your USA Second Offense CUE, and let the GUI install the game. Keep all included mods beside the executable.

The base-game installation is extracted from your BIN/CUE; it is not included in this archive. All five runtime mods and their required assets are included. The optional original-V8 soundtrack is not bundled.

Project and issue reports: https://github.com/GTTeancum/Vigilante-8-recomp

This candidate includes the guest VRAM correction and GUI first-run setup. It is work in progress. See SETUP.md for the tested scope, requirements, controls, troubleshooting and backup instructions.

`release-manifest.json` records the packaged file sizes and integrity hashes. Those hashes verify the release contents; they are not used to reject a user's disc image.
