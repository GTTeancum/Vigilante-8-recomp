## Working Converter Behavior

The working build is generated by:

- `tools/i76_marshal_v82_test_package.py`

Important behavior:

- Replaces `guest.v8.beezwax` with display name `I76 Ransom Marshal Test`.
- Pulls the body mesh from `RM11BDYM`.
- Pulls the separated glass mesh from `GLASS`.
- Excludes wheels, guns, and separate light meshes from the baked body.
- Keeps glass separate from diffuse texture.
- Uses V8:2 environment/glass packet kind `12` for the glass triangles.
- Uses atlas-textured body triangles, not gray proxy face colors.
- Reverses triangle winding and UV order together before native compilation because Blender-to-native coordinate conversion changes handedness.
- Uses textured packet kind `13` for the body to avoid the bad flat-lit normal path that made the car render nearly black.
- Uses an indexed 256-color atlas texture with palette index `0` reserved and unused. This avoids treating the dominant dark atlas background as special/transparent black.
- Copies selector portrait assets into `final/SHELL` so `RECOMPONE_V82_VEHICLE_PACKAGE` can point directly at the test package.
- Gives the selector preview its own Marshal body/glass bank instead of inheriting Beezwax's preview bank.

## Failed Attempts / Do Not Repeat

1. Merely forcing `--guest-vehicle guest.v8.beezwax` is not enough. The process must have `RECOMPONE_V82_VEHICLE_PACKAGE` set to the Marshal package folder, or it loads the default Beezwax package.

2. The forced package folder must include `SHELL/SELECTOR_*.PPM`, otherwise V8:2 dies while validating selector portraits.

3. Inheriting Beezwax's selector preview bank is wrong. Gameplay can show Marshal while selector still shows Beezwax unless `selector_preview_bank` is also replaced.

4. Feeding Blender triangle order directly into native output is wrong. The converted mesh appears inverted/culling-wrong. Reverse triangle winding and reverse matching UV order together.

5. Direct 16-bit `256x256` texture is too heavy for the selector path. It caused selector acceptance to capture only slots `10, 11` and fail before the full roster cycle.

6. A naive 8-bit palette with black as palette index `0` makes the Marshal render as a dark/black silhouette. Reserve palette index `0` and do not assign body texels to it.

7. Flat-lit textured body packet kind `5` with generated normals made the body render nearly black. Packet kind `13` gave the working visible textured body in the selector.

8. Replacing textures with atlas-sampled solid face colors made a coherent gray proxy but was not acceptable because it removed the actual mapped Marshal texture.
